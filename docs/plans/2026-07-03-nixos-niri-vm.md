# NixOS + niri Evaluation VM — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a persistent NixOS + niri VM on the EndeavourOS host from a pinned flake, boot into a usable niri desktop, then port the user's neovim config the idiomatic (Mason-free) way as the first in-VM iteration.

**Architecture:** A flakes-based NixOS config in `~/nixos-config`, structured multi-host from day one. Stable nixpkgs `25.05` base + a `nixpkgs-unstable` overlay (`pkgs.unstable.*`) + `niri-flake` for niri nightly. Home Manager runs as a NixOS module so one `nixos-rebuild switch` applies system + user config. The VM runs under libvirt/QEMU/KVM with UEFI + SPICE. NixOS is installed by booting the official minimal ISO and running `nixos-install --flake`.

**Tech Stack:** Nix flakes, NixOS 25.05, Home Manager, niri-flake, libvirt/virt-manager/QEMU, greetd+tuigreet, ghostty, waybar, fuzzel, mako, neovim (lazy.nvim).

**Verification model:** This is infra/config, not app code — there is no pytest. "Tests" are: `nix flake check`, `nix build .#nixosConfigurations.nixos-vm.config.system.build.toplevel`, and explicit boot/behaviour checks. The host has **no Nix**, so all Nix *evaluation* happens on the installer ISO or inside the VM. Authoring + git happen on the host.

**Repo transport:** `~/nixos-config` and `~/dotfiles` are pushed to GitHub (user has `gh` configured) and cloned inside the VM. This is how the flake and the nvim dotfiles reach the guest.

No Nix on the host, so we only author + commit here. Evaluation happens in Phase 5.

### Task 1: flake.nix

**Files:**
- Create: `~/nixos-config/flake.nix`

- [ ] **Step 1: Write flake.nix**

```nix
{
  description = "NixOS + niri configuration (VM eval, multi-host)";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-25.05";
    nixpkgs-unstable.url = "github:NixOS/nixpkgs/nixos-unstable";

    home-manager = {
      url = "github:nix-community/home-manager/release-25.05";
      inputs.nixpkgs.follows = "nixpkgs";
    };

    niri-flake.url = "github:sodiboo/niri-flake";
  };

  outputs = { self, nixpkgs, nixpkgs-unstable, home-manager, niri-flake, ... }:
    let
      system = "x86_64-linux";

      # Overlay exposing nightly packages as pkgs.unstable.<name>
      unstableOverlay = final: prev: {
        unstable = import nixpkgs-unstable {
          inherit (prev) system;
          config.allowUnfree = true;
        };
      };
    in
    {
      nixosConfigurations.nixos-vm = nixpkgs.lib.nixosSystem {
        inherit system;
        specialArgs = { inherit niri-flake; };
        modules = [
          { nixpkgs.overlays = [ unstableOverlay niri-flake.overlays.niri ]; }
          niri-flake.nixosModules.niri
          ./hosts/nixos-vm/configuration.nix
          ./modules/desktop-niri.nix

          home-manager.nixosModules.home-manager
          {
            home-manager.useGlobalPkgs = true;
            home-manager.useUserPackages = true;
            home-manager.users.danielh = import ./home/danielh.nix;
          }
        ];
      };
    };
}
```

  programs.niri.enable = true;
